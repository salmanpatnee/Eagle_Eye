## Coding Conventions

### PHP/Laravel
- Namespace: PSR-4 (`App\` → `app/`)
- Models: `$guarded = []` for mass assignment
- Timestamps: some models disable with `public $timestamps = false`
- DB tables: snake_case; pivots use `table1_vs_table2_table` format
- Custom table names via `protected $table`
- Fat controllers pattern; some logic in Services

### Database
- Primary keys: custom names (`risk_id`, `asset_id`, etc.)
- Foreign keys: `_id` suffix
- Table naming: `risk_master_table`, `control_master_table`, etc.

### Frontend
- Blade templates with component-based structure
- Tailwind CSS utility classes
- AJAX via Axios

## Security Notes

- `$guarded = []` on models — always validate request input
- CSRF enabled on POST/PUT/DELETE
- Never commit `.env`
- Use query builder/Eloquent, not raw SQL strings

## Common Issues

1. Vite broken → run `npm run dev`
2. Permission errors → check `storage/` and `bootstrap/cache/` write perms
3. DB connection → verify MySQL running + `.env` credentials
4. Assets not loading → run `npm run build`
5. New Tailwind class (e.g. a `grid-cols-N` never used before) has no effect on the server, even after pulling and clearing every cache:
   - Cause: the app's Tailwind CSS isn't built by Laravel's own Vite pipeline — it's a separate pre-built TailAdmin theme bundle at `public/tailadmin/build/style.css` (loaded via `<link>` in `resources/views/partials/header.blade.php`), generated by a webpack build inside `public/tailadmin/` (Tailwind JIT scans that folder's `src/` for classes actually used). `public/tailadmin/.gitignore` ignores `/build`, so this compiled CSS is normally invisible to git — a brand-new utility class only exists wherever someone last ran the build locally, and never reaches the server through `git pull`.
   - Fix: `cd public/tailadmin && npm run build`, then `git add -f public/tailadmin/build/style.css` (only that file — not the rest of `build/`, which is ~170 unrelated TailAdmin demo template pages) and commit/push. No cache clear needed on the server; `git pull` alone picks up the new static CSS.
   - Do this any time a Blade change introduces a Tailwind utility class that nothing else in the codebase already used.
