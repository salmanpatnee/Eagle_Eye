BRANCH SUMMARY: 001-m2m-data-import
=====================================

Data Import Engine for Many-to-Many Relationships


CORE FEATURE
------------
- Built a system to import many-to-many relationship data from Excel/CSV files into pivot tables
- Handles files with primary entity IDs and comma-separated related IDs
- Supports up to 100,000 rows per import


DATABASE & MODELS
-----------------
- Created `import_mappings` table and `ImportMapping` model for configuring import templates
- Created `import_jobs` table and `ImportJob` model for tracking import history and status
- Configured logging channel for import operations in `config/logging.php`


BACKEND SERVICES
----------------
- SpreadsheetParserService - Parses Excel/CSV files using maatwebsite/excel
- ImportValidatorService - Validates entity IDs and identifies malformed data
- RelationshipImporterService - Handles insertion into pivot tables with transactional integrity
- ProcessImportJob - Background queue job for processing large imports


CONTROLLERS & ROUTES
--------------------
- ImportMappingController - Manages import mapping configurations
- ImportController - Handles file uploads and dispatches import jobs
- ImportHistoryController - Provides import job history and detailed logs
- Added routes in `routes/web.php` under `/admin/imports`


SECURITY & VALIDATION
---------------------
- VerifyImportAccess middleware for RBAC (role-based access control)
- ImportFileUploadRequest for file upload validation
- Audit trails and logging for all import activities
- Data sanitization and security hardening for import endpoints


FRONTEND UI
-----------
- File upload component (`resources/views/components/file-upload.blade.php`)
- Import manager interface (`resources/views/admin/import-manager/`)
- Import history viewer with detailed error logs
- JavaScript for interactive file uploads (`public/js/import-manager/`)


ERROR HANDLING
--------------
- Gracefully handles invalid entity IDs
- Reports malformed relationship data
- Skips invalid entries while processing valid ones
- Provides detailed import summaries with error reporting
- Ignores duplicate relationships
